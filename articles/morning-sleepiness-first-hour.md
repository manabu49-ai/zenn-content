朝、起きた直後の30〜60分がまったく使いものにならない。

私はこれを長いあいだ「気合いの問題」だと思っていました。**違いました。**起床直後に頭が回らないのは、体の側の仕様です。名前もついています。**睡眠慣性（sleep inertia）**といいます。

仕様なら、根性ではなく**手順**で扱えます。

## まず、何が起きているのか

睡眠から覚醒への切り替えは、スイッチではなく**傾斜**です。目が覚めた瞬間に脳のすべてが起動するわけではなく、判断や段取りを担う部分ほど立ち上がりが遅い。

だから朝一に起きるのは、こうなります。

```
起きた直後にできること      できないこと
------------------------  ------------------------
手を動かす作業             優先順位を決める
決まった手順をなぞる       設計する・見積もる
読む（流し読み）           重要なメールに返信する
```

**「眠い」の正体は、体力ではなく判断力の欠落です。**
ここを取り違えると、対処法を全部まちがえます。

## 効くもの

順番に意味があります。上から順に、起床後の時間軸に沿って並べています。

### 1. スヌーズを止める

二度寝の10分は、睡眠としては短すぎて回復に寄与せず、**傾斜のやり直しだけが増えます。**起きる時刻を後ろにずらすほうが、同じ睡眠時間でも目覚めはましになります。

**アラームは1回。鳴ったら止めて、座る。**

### 2. 光を浴びる（最優先）

体内時計を動かす入力のうち、群を抜いて強いのが光です。しかも**屋外の曇天のほうが、室内の照明よりはるかに明るい。**

- カーテンを開ける（起きて最初の動作にする）
- できれば外に出る。ベランダで十分
- 5〜15分

これは「気分がいいから」ではなく、**その日の夜の眠気の時刻を決める操作**でもあります。朝の光は、当日の目覚めと今夜の寝つきの両方に効きます。

### 3. 体温を上げる

眠気は深部体温が下がっている状態と結びついています。上げる手段はどれでもよく、**組み合わせるほど早い。**

- 熱いシャワー（顔だけでも可）
- 水を1杯。寝ている間の脱水は、それ自体が倦怠感になる
- 5分歩く。運動ではなく、体温のスイッチとして

### 4. カフェインは「起きた直後」ではない

コーヒーは飲んだ瞬間には効きません。**効き始めるまでに20〜30分、ピークは30〜60分後**です。

つまり、起き抜けの1杯は、いちばん眠い時間帯には間に合っていない。**起きてすぐ淹れて、飲むのは支度のあと**にすると、効きどころがずれません。

夕方以降に効くのを避けたいなら、**「就寝の6〜8時間前まで」**を目安に切り上げます。カフェインの半減期は個人差が大きいので、ここは自分で試すしかありません。

### 5. 15〜20分の仮眠（昼まで持たないとき）

どうしても落ちる日は、**20分を超えないタイマー**で寝る。超えると深い睡眠に入り、起きたときにまた睡眠慣性をやり直すことになります。

コーヒーを飲んでから寝ると、**目覚める頃にカフェインが効き始めます。**

## 効かないもの、あるいは逆効果のもの

```
やりがちなこと            実際に起きること
----------------------  ----------------------------
スヌーズで二度寝          目覚めの傾斜が増えるだけ
朝一で重い判断をする      判断力が最低の時刻に決める
週末に寝だめ              月曜の体内時計が後ろにずれる
朝の甘い菓子パン          直後の眠気が戻る
起き抜けのスマホ          光は弱く、判断力だけ消耗する
```

**週末の寝だめは、いちばん見落とされます。**土日に3時間ずらすと、月曜の朝は時差ぼけと同じ状態から始まります。起床時刻は、就寝時刻より優先して固定するほうが安定します。

## いちばん効いたのは「順番を変える」ことだった

対処法をひととおり試して、最終的にいちばん効いたのは、**眠気を消すことではありませんでした。**

**眠くても壊れない仕事を、朝一に置いたことです。**

```
起床直後（〜60分）    手順が決まっている作業、掃除、読むだけの確認
そのあと            設計、見積もり、返信、意思決定
```

判断力が戻る前の時間帯に、判断を必要とする仕事を置かない。それだけで、「朝が使えない」という感覚がかなり消えました。

眠気は消せませんが、**眠気とぶつかる仕事の配置は、こちらで決められます。**

## まとめ

```
1  アラームは1回。スヌーズを使わない
2  起きて最初の動作をカーテンにする（外に出られればなお良い）
3  水・熱いシャワー・5分歩く で体温を上げる
4  コーヒーは起きてすぐ淹れ、飲むのは20〜30分後
5  重い判断は、起床60分後より後ろに置く
```

上から順に、**1と2だけでも変わります。**全部やろうとすると続かないので、まずその2つを。

:::message
この記事は一般的な睡眠のしくみと、自分の生活での運用を書いたものです。十分に寝ているのに日中の眠気が続く場合、睡眠時無呼吸などが背景にあることがあります。その場合は対処法ではなく、受診のほうが早いです。
:::
